# MudBlazor

This project uses MudBlazor as its primary UI framework.

Always:

- Prefer MudBlazor components over raw HTML when an equivalent exists.
- Follow MudBlazor design patterns.
- Use MudGrid and MudItem for layouts.
- Use MudTable or MudDataGrid instead of HTML tables.
- Use MudDialog for dialogs.
- Use MudSnackbar for notifications.
- Use MudForm together with validation.
- Prefer MudIcon and MudButton.
- Use MudStack for simple layouts when appropriate.
- Prefer javascript functions for simple animations

Avoid:

- Using heavy MudBlazor components and theming
- Bootstrap components.
- Tailwind classes.
- Third-party component libraries.
- Mixing HTML controls with MudBlazor equivalents unless necessary.
